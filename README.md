# 🧠 Self – ربات شخصی مدیریت پروفایل تلگرام

[![Python](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/downloads/)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![Telegram](https://img.shields.io/badge/Telegram-@theesmaeil-blue.svg)](https://t.me/theesmaeil)

**Self** یک ربات سبک، سریع و کاملاً شخصی‌سازی‌شده برای مدیریت خودکار پروفایل تلگرام شماست.  
با این ربات، بدون نیاز به تایپ `/` (اسلش)، بیوگرافی و نام خود را به‌روز نگه دارید، محتوای تایم‌دار را ذخیره کنید و اطلاعات کاربران را در لحظه دریافت کنید.

---

## ✨ ویژگی‌های کلیدی

| قابلیت | توضیح |
|--------|--------|
| ⏰ **زمان لحظه‌ای** | نمایش خودکار زمان (به‌وقت تهران) در بیوگرافی و نام خانوادگی |
| 🖼️ **ذخیره‌ی خودکار** | عکس‌ها و ویدیوهای خودتخریب‌شونده (`ttl_seconds`) مستقیماً به Saved Messages فرستاده می‌شوند |
| 📋 **دستورات کاربردی** | `help`، `status`، `setbio`، `save`، `id`، `data` – همه بدون اسلش |
| 🧹 **چت تمیز** | پیام‌های دستوری پس از اجرا به‌طور خودکار حذف می‌شوند |
| 🔒 **امنیت بالا** | تمام دستورات فقط برای خود شما (ارسال‌کننده) معتبر هستند |
| ⚡ **واکنش‌گرا** | با استفاده از `asyncio` و `APScheduler`، به‌روزرسانی‌ها در پس‌زمینه انجام می‌شوند |

---

## 🚀 نصب و راه‌اندازی سریع

### ۱. کلون کردن مخزن
```bash
git clone https://github.com/theesmaeil/self.git
cd self
```

### ۲. نصب وابستگی‌ها
```bash
pip install -r requirements.txt
```

### ۳. تنظیم اطلاعات حساب کاربری
فایل `self.py` را باز کرده و مقادیر زیر را با اطلاعات خود از [my.telegram.org](https://my.telegram.org/apps) تکمیل کنید:
```python
API_ID = 1234567          # عددی
API_HASH = 'your_api_hash'
SESSION_NAME = 'self_session'
```

> **توصیه امنیتی:** برای جلوگیری از درج مستقیم اطلاعات در کد، از متغیرهای محیطی یا فایل `.env` استفاده کنید.

### ۴. اجرا
```bash
python bot.py
```

پس از اولین اجرا، یک فایل نشست (`self_session.session`) ساخته می‌شود و در صورت نیاز کد تأیید از تلگرام دریافت خواهید کرد.

## 📌 دستورات (همگی در Saved Messages)

| دستور | عملکرد | مثال |
|-------|--------|-------|
| `help` | نمایش راهنمای کامل | `help` |
| `bot` | اعلام آنلاین بودن با نام شما | `bot` |
| `status` | مشاهده‌ی وضعیت فعلی تنظیمات | `status` |
| `timebio on/off` | فعال/غیرفعال کردن نمایش زمان در بیو | `timebio on` |
| `timename on/off` | فعال/غیرفعال کردن نمایش زمان در نام | `timename off` |
| `setbio` (ریپلای روی متن) | تنظیم بیوگرافی با همان متن (زمان خودکار اضافه می‌شود) | ریپلای روی یک پیام متنی و ارسال `setbio` |
| `save` (ریپلای روی هر پیام) | کپی کردن پیام مورد نظر به Saved Messages | ریپلای و ارسال `save` |
| `id` (ریپلای روی کاربر) | نمایش اطلاعات کامل آن کاربر (شناسه، یوزرنیم، وضعیت و ...) | ریپلای روی پیام کاربر و ارسال `id` |
| `data` (ریپلای روی پیام) | نمایش داده‌ی خام (raw) پیام به صورت کد | ریپلای و ارسال `data` |

## ⏰ تنظیم منطقه‌ی زمانی

ربات به‌طور پیش‌فرض از منطقه‌ی زمانی **تهران (Asia/Tehran)** استفاده می‌کند.  
برای تغییر، در توابع `update_bio_with_time` و `update_name_with_time` خط زیر را ویرایش کنید:
```python
tz = pytz.timezone('Asia/Tehran')   # منطقه‌ی دلخواه خود را وارد کنید
```
